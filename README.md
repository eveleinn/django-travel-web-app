# Веб-приложение на Django с использованием MySQL

Веб-приложение для бронирования туров, разработанное на Django  с использованием MySQL. Проект включает систему бронирования туров, авторизацию пользователей и административную панель для управления контентом.

## 🎯 Функциональность

- Регистрация и авторизация пользователей
- Просмотр каталога туров, фильтрация по сложности, стоимости и продолжительности
- Бронирование туров для авторизованных пользователей
- Административная панель для управления турами и бронированиями

## 📁 Состав проекта mysite

- `accounts/` – основное приложение, содержащее модели (туры, бронирования), представления, формы и маршруты.
- `static/` – статические файлы: CSS, JavaScript, изображения.
- `templates/` – HTML-шаблоны для всех страниц.
- `travel_site/` – папка с настройками проекта (settings.py, urls.py, wsgi.py, asgi.py).
- `manage.py` – утилита командной строки Django для управления проектом.

- ## 🚀 Инструкция по развертыванию проекта

1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/eveleinn/django-travel-web-app.git
   cd django-travel-web-app
   ```
2. Создайте и активируйте виртуальное окружение:
   **Windows:**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
   **Linux / Mac:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Установите необходимые библиотеки:
   ```bash
   pip install Django Pillow PyMySQL
   ```
4. Настройте базу данных MySQL
  - Запустите MySQL через XAMPP
  - Для удобства запустите phpMyAdmin
  - В phpMyAdmin создайте базу данных **`travel`** и импортируйте в нее файл **`travel.sql`** (в репозитории)

> Файл `travel.sql` содержит структуру всех таблиц и тестовые данные. Это позволяет сразу увидеть, как устроена база данных.

5. Настройте подключение к базе данных: откройте файл **`travel_site/settings.py`** и в блоке `DATABASES` укажите параметры вашего MySQL

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'travel',
        'USER': 'root',          # ваш логин к MySQL
        'PASSWORD': '',          # ваш пароль (по умолчанию пустой)
        'HOST': 'localhost',
        'PORT': '3306',
    }
}
```
7. Запустите сервер Django:
```bash
python manage.py runserver
